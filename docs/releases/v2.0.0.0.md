Fast Screen Off 2 adds packages for **Deepin 25** and **Debian 13**, with screen
power control for X11 and supported Wayland desktops.

## Changes since v1

- Choose the screen-power backend for the current session: X11 DPMS, GNOME
  Mutter, KDE KScreen, or `wlopm` on compatible Wayland compositors such as
  Treeland.
- Report missing helpers and unsupported sessions with an explanation and,
  when available, a desktop notification. Never fall back to XWayland for
  physical display power control.
- Keep the default 0.5-second launch delay and add `--delay SECONDS`, `--help`
  and `--version` options.
- Provide separate Debian packages using standard `/usr` paths and Deepin
  packages using `/opt/apps/net.playhi.fast-screen-off`.
- Automate package builds, validation, installation/removal checks, release
  assets and SHA256 checksums.

The package ID remains `net.playhi.fast-screen-off`, so existing installations
can upgrade normally. The application turns off displays; it does not suspend
the computer or change idle timers. Your desktop's lock policy still applies.

## Download and install

Download **one** package matching your system, plus `SHA256SUMS` if you want to
verify the download. Both packages contain architecture-independent scripts and
data; runtime dependencies are supplied by your distribution.

```sh
# Debian 13
sudo apt install ./net.playhi.fast-screen-off_2.0.0.0_debian13_all.deb

# Deepin 25
sudo apt install ./net.playhi.fast-screen-off_2.0.0.0_deepin25_all.deb

# Verify whichever release package(s) you downloaded
sha256sum --check --ignore-missing SHA256SUMS
```

On immutable Deepin installations, use the system's supported package installer
or update mechanism. Then launch **Fast Screen Off / 快速熄屏** from the application
menu. Mouse or keyboard input wakes the displays.

## Compatibility and validation

- X11 requires DPMS support from the X server and display driver.
- GNOME Wayland uses the active session bus. KDE Wayland needs `libkscreen-bin`.
- Treeland and other compatible Wayland compositors need `wlopm` and the
  `zwlr_output_power_manager_v1` protocol. APT installs `wlopm` as a recommendation
  when it is available; repository availability varies across Deepin builds.
  Use an X11 session if the required Wayland helper or protocol is unavailable.
- CI checks both packages in amd64 Debian 13 and Deepin 25 containers, including
  23 mocked backend tests, shell/desktop validation, package contents,
  installation and removal. Physical display power-off/wake-up and other CPU
  architectures have not been tested.
